## 1. 설치 (처음 한 번)

| 필요한 것 | 확인 | 없으면 |
| --- | --- | --- |
| git | 터미널에 `git --version` | Mac: `xcode-select --install` · Windows: git-scm.com |
| Node 18 이상 | `node -v` | nodejs.org 에서 LTS 설치 |
| Claude Code | `claude --version` | Mac: `curl -fsSL https://claude.ai/install.sh \| bash` · Windows(PowerShell): `irm https://claude.ai/install.ps1 \| iex` |

설치 뒤 터미널에서 `claude` 를 실행하고 Claude 계정으로 로그인합니다.

