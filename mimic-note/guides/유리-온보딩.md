# 유리님 온보딩 (관리자 3순위)

GitHub: `emileepark5281-cmd` · 아이디: `yuri`

## 1. 창민님이 먼저 할 일
mimic 저장소 → Settings → Collaborators → **Add people** → `emileepark5281-cmd` → **Write** 권한으로 초대 (미션 M-0014)

## 2. 유리님이 할 일
1. GitHub 메일(또는 github.com/newcode135-prog/mimic-note/invitations)에서 초대 **수락**
2. 아래 프롬프트를 Claude Code 에 **통째로 붙여넣기**

```
유리 https://github.com/newcode135-prog/mimic-note

나는 미믹노트 관리자(3순위) 유리야. GitHub 아이디는 emileepark5281-cmd.
1) 저장소가 없으면 ~/mimic 에 git clone, 있으면 git pull 해 줘.
2) 저장소의 CLAUDE.md 0번 규칙대로 `node mimic-note/checkin.mjs 유리` 를 실행해 줘.
3) ① 대전제를 먼저, ② 내 미션을 그다음에 그대로 보여 주고, 이 세션 동안 대전제를 따라 줘.
4) push 가 안 되면 `gh auth login` 으로 emileepark5281-cmd 로그인을 도와줘.
```

다음부터는 첫 줄만 보내면 됩니다: `유리 https://github.com/newcode135-prog/mimic-note`
(`emileepark5281-cmd https://github.com/newcode135-prog/mimic-note` 도 같은 로그인)
