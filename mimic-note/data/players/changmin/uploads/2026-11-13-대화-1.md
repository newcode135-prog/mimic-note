## 1. [데이터 라벨링] — 이 대화에서 나온 [ ] 언어

`[ ]` 는 **서로 다른 모양의 것들에서 공통점을 찾아 하나의 이름으로 묶는 이 노트의 언어**입니다. `[단어 [단어]]` 처럼 겹쳐 쓸 수 있습니다. 라벨을 붙이는 행위 자체가 [데이터 라벨링]입니다.

| 라벨 | 이 대화에서 묶은 것들 | 공통점 |
| --- | --- | --- |
| [초월] | 새 저장소 이름 → 회사원=게임 플레이어 미션 시스템의 이름 | 사람의 일을 게임처럼 넘어서게 하는 체계 |
| [미믹노트] | 미믹 저장소 안의 `mimic-note/` · 기록장 · 규칙집 | 모든 것이 모이는 한 장소 |

## 2. [데이터 압축] — 결정만 남긴 흐름

1. **출발** — 미믹 저장소(클라우드 드라이브 기획)를 Claude Code 에 넘겨도 되는지 확인.
2. **정체 바로잡기** — 미믹은 회사원이자 게임 플레이어들에게 전달할 투두리스트. 아이디별 미션, 동시 업로드, 압축·소거로 과부하 방지.
3. **[초월]** — 새 저장소를 만들었다가, [중앙 컴퓨터]는 미믹 저장소의 [미믹노트]로 정함.
4. **역할** — 창민 대표관리자(최종 권한), 민호 2순위 관리자. 팀원 유리·네이뜬·루카스.
5. **초월 가이드 1번** — MIMIC TASK 지시서 검토(원본은 `mimic-note/guides/`).
6. **체크인** — `이름 + 링크` 를 받으면 Claude Code 가 그 사람의 투두를 전달. 텔레그램은 나중.
7. **미션 데이터베이스** — `data/missions.json`, 관리자만 추가, 본인만 완료.
8. **루카스 접속 실패** — 장치는 정상, 미션이 0개라 실패처럼 보임.
9. **[로그인 규칙]** = 암호구. 들어오면 **[대전제] → 미션 → 자동 투두** 순서.
10. **[패시브 스킬] [자동 다운로드]** — 각자 자기 칸에만 기록 → 10분마다 모아서 계산 → 바뀐 사람에게만 알림. 결정: 맥미니(A) · 텔레그램은 창민이 연결(B) · 규칙 우선, 필요할 때 AI, AI 하네스는 주인 구함(C) · 알림은 투두 변경·더 중요한 일만(D).
11. **보상 규칙** — 미정, 나중에 다시 검토.
12. **[데이터 라벨링]의 정의** — `[ ]` 안에 넣어 공통점을 묶는 이 노트만의 언어. 사고력을 넓히는 도구.
13. **지금** — 이 대화를 라벨링·압축해서 창민의 자기 칸에 [업로드].
